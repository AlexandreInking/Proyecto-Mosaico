## Leyenda de evidencia

- **Implementado:** visible en código y/o cubierto por pruebas.
- **Verificado:** comprobado en el corte indicado.
- **Planificado:** aparece en documentación o backlog; no es una feature vendible.
- **Inferencia:** recomendación derivada de evidencia, no hecho demostrado.
- **Pendiente:** requiere prueba manual, decisión de producto o fuente externa.

## Decisiones fijadas

- Mosaico se presenta como **2D Asset Workspace**, no como producto de IA.
- Primer beachhead: creador indie 2D, technical artist o level designer en equipo pequeño.
- Desktop Windows es la única superficie de producto y distribución del Hito 1.1; Web queda fuera del release.
- Publicación itch.io pública, de pago y sin demo separada.
- Precio de lanzamiento recomendado: **US$14.99**; precio estable objetivo: **US$19.99** si la validación confirma valor.
- Diez testers reciben download keys de itch.io. No se implementan licencias dentro de Mosaico.
- No se realizan publicaciones, ventas, cuentas externas ni cambios de código como parte de este paquete.

## Método de investigación

Las funciones se contrastan contra el repositorio, manuales, contratos y pruebas. Precios, licencias, comisiones y requisitos de tiendas se contrastan contra documentación oficial. Reddit y otras comunidades sirven para detectar lenguaje y fricciones, no para estimar tamaño de mercado. Cada documento separa hechos, señales e inferencias.
